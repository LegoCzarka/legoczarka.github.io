💡 Podpowiedź: Co Czarek lubi najbardziej i jak sprawdzić pudełko w sklepie?

Każde pudełko LEGO ma na przodzie duży 5-cyfrowy numer (np. 60414). Wpisz ten numer w pole powyżej: jeśli wyskoczy zielony komunikat, to znaczy, że zestawu jeszcze nie mamy! Czarek najbardziej lubi poniższe serie:

🔑 Odświeżanie z Rebrickable (konfiguracja)

Aby uruchamiać aktualizację kolekcji jednym kliknięciem z tej strony (maksymalnie raz na 6 godzin), zapisz jednorazowo token GitHub. Token jest zapisywany wyłącznie lokalnie w Twojej przeglądarce i nigdy nie trafia do kodu strony.

  1. Otwórz GitHub → New fine-grained token ↗
  2. W sekcji Repository access wybierz Only select repositories → legoczarka/legoczarka.github.io
  3. W Repository permissions ustaw wyłącznie Actions: Read and write, wygeneruj token i wklej go poniżej:
⚙️ Otwórz GitHub Actions ↗
